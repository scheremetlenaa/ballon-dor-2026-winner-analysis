# Manual inputs

Facts the sources don't provide, merged by the ETL on every run (names matched by slug, Wikipedia spelling).

| File | Contents |
|---|---|
| `players.csv` | SofaScore ID, position group, birth date, nationality |
| `competition_overrides.csv` | stage reached / trophy corrections, e.g. the 2025 MLS Cup |
| `first_place_votes.csv` | first-place votes, when published |
| `top_opponents.csv` | extra "top" opponents, e.g. national teams |
| `ratings.csv` | rating corrections |
